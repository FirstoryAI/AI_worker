# 두 덩어리면 양쪽 면에 (2026-11-15)

## 왜
쪽 글이 어떤 쪽은 왼쪽·오른쪽 면에 나뉘고, 어떤 쪽은 한 면에 몰려 나온다(팀 피드백). 11/14 진짜 모델 「분홍 길을 그린 날」 10쪽: 한 면 8쪽, 양쪽 2쪽.
원인: 2덩어리여도 자리 찾기 AI·`settle`이 같은 면 위·아래를 허용하고, 자리가 없으면 두 덩어리를 하나로 합친다.

## 목표 / 안 할 것
- 목표: **2덩어리 쪽은 양쪽 면에 빈 곳이 있으면 1번은 왼쪽 면, 2번은 오른쪽 면에 나눠 두고, 빈 곳이 한 군데뿐이면 합쳐서 그곳에 둔다** (사용자, 11/15 수정).
  처음 규칙("2덩어리면 무조건 양쪽")은 기존 그림 시험에서 7쪽이 곰 발 근처 모래 위로 가는 등 더 나빠져서 바꿨다.
- 안 할 것: 덩어리 나누기 기준(`text_chunks.md`, 1 또는 2덩어리)은 그대로. 1덩어리(짧은 쪽 포함)는 지금처럼 한 면.
- 실패로 볼 것: 양쪽에 빈 곳이 있는데 한 면에 몰리는 것. 한 군데에 깔끔히 둘 수 있는데 나눠서 복잡한 곳에 얹는 것. 그림·글이 아예 안 나오는 것.

## 고른 방법
- A. 프롬프트만(`text_place.md`): 싸지만 `settle`이 같은 면에서 먼저 찾고 합치기도 해서 보장 못 함.
- **B. 프롬프트 + 코드 (사용자 선택)**: 그림·자리 프롬프트에 면을 정해 주고, 코드도 그 면 안에서만 찾게.

## 바꿀 것
1. `prompts/text_place.md`: 2덩어리면 1번은 왼쪽 면, 2번은 오른쪽 면 안에 (같은 면 위·아래 금지). 1덩어리 조건은 그대로.
2. `illustrate.layout_prompt`: 2덩어리면 첫 그리기부터 "하나는 왼쪽 면, 하나는 오른쪽 면"의 위나 아래에 빈 곳을 남기라고. 다시 그릴 때 `where`는 `left top` / `right top`으로 고정(지금은 `_side`가 AI 자리로 정함).
3. `layout.settle`: 2덩어리면 덩어리 i는 정해진 면(0=왼쪽, 1=오른쪽)에서만 찾는다(`_search`가 반대 면으로 넘어가지 않음). AI가 반대 면에 답하면 정해진 면 안으로 민다.
4. `layout.calmest`: 2덩어리면 덩어리마다 정해진 면에서만 가장 덜 복잡한 곳.
5. `illustrate._arrange` 순서 (2덩어리일 때, 11/15 수정):
   ① 양쪽 자리 찾기(`settle`, 면 고정) → ② 안 되면 합친 한 덩어리 자리 찾기 → ③ 둘 다 안 되면 **다시 그리기**(왼쪽 위·오른쪽 위, 실행당 2쪽까지, 원래 있던 기능 그대로) 뒤 ①·② 다시
   → ④ 그래도 없으면 양쪽 `calmest`와 합친 `calmest` 중 덜 복잡한 쪽(나눈 쪽은 두 자리 중 더 복잡한 값, 같으면 나눈 쪽. Claude 판단) → 기본 자리.
   ①·②의 순서는 예전과 같아 다시 그리기 횟수도 예전과 같다. 1덩어리 순서는 그대로.
   다시 그리기를 뺄지는 이 일과 따로 정한다(진짜 모델로 한 편 볼 때 횟수·효과를 보고).
6. 확인 스크립트: `evals/layout_run.py`의 두 덩어리 settle 사례(3, 3-1, 3-2)를 새 규칙에 맞게 고친다. 새 사례: 같은 면 답 → 면이 갈림, 오른쪽만 복잡 → settle은 None, 나눌지 합칠지 고르기는 합친 쪽(왼쪽 한 군데). `evals/mock_run.py`: 8-7(합친 자리가 있으면 다시 그리지 않고 합침)은 예전대로, 둘 다 없으면 왼쪽 위·오른쪽 위로 다시 그리기.

## 영향
- 다시 그리기 횟수는 예전과 같다(합친 자리를 먼저 보므로).
- 기존 그림 시험(「분홍 길을 그린 날」, `out/two-blocks-sides-1115.html`): 2·3·8쪽 양쪽, 7·9·6쪽은 합친 자리가 덜 복잡해 한 면, 10쪽은 거의 같아 양쪽.
- API·`text_blocks` 형식·프론트 변화 없음.

## 확인
- `uv run python evals/layout_run.py`, `uv run python evals/mock_run.py` 통과.
- 진짜 모델 한 편(비용 먼저 묻기)으로 2덩어리 쪽이 모두 양쪽인지, 다시 그리기 몇 번인지 센다.
