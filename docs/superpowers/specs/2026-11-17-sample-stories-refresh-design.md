# 홈 샘플 동화 8편 의성어·글 배치 최신화 (짧은 설계)

2026-11-17. 관련: [Backend#45](https://github.com/FirstoryAI/Backend_Mainpage/issues/45)(샘플 8편), [AI#113](https://github.com/FirstoryAI/AI_worker/issues/113)(조용한 자리면 다시 그리지 않기)

## 왜

홈 카드 팝업의 예시 동화 8편(`~/Desktop/FIRSTORY/샘플동화/<카드id>/`, 프론트 `src/assets/sample-stories/`)은 11/6에 만들었다. 그 뒤 바뀐 것이 반영되지 않았다.

- 프론트 본문 글자가 1.65 → 2.35cqw로 커졌는데, 샘플 `textBlocks`는 옛 크기로 계산돼 있어 글이 잘린다(사용자가 본 문제)
- 의성어·의태어를 그림 위에 띄우는 `soundWord`가 없다
- 글이 캐릭터를 피하는 배치(#107)가 들어가기 전이다

## 목표 / 하지 않을 것

- 목표: 8편의 `story.json` 각 쪽 `textBlocks`·`soundWord`를 지금 파이프라인 기준으로 다시 만들어, 지금 폴더 양식 그대로 프론트에 넘긴다
- 하지 않음: 이야기 글 새로 쓰기(별표 의성어는 이미 글에 있음), 앞·뒤표지(프론트가 아직 안 씀, #45에서 안 넣기로 함), 대화 가이드 질문(샘플은 가이드 없음 그대로)
- 실패로 보는 것: 11/6에 다듬은 이야기·그림이 사용자 동의 없이 바뀌는 것, 글이 캐릭터 얼굴·몸을 가리는 것

## 방식 (검토한 것)

- A. 같은 팝업 문구로 8편 처음부터 다시 생성: 약 6,700원 이상, 피드백 반복, 다듬은 이야기가 사라짐 → 안 함
- B. 지금 글·그림은 두고 글 자리·의성어 자리만 다시 잡기 → **선택(사용자)**
- 남는 "자리 없는 쪽" 처리는 셋 중 3번 **"먼저 보고 정하기"(사용자 선택)**:
  1. 다시 안 그리고 가장 조용한 곳에 둠
  2. 자리 없는 쪽만 다시 그림
  3. 80쪽을 1번으로 배치한 미리보기를 보고, 사용자가 고른 쪽만 2번으로

## 할 일

1. **AI#113 먼저**(이슈 → PR, main 합침): 다시 그리기 전에 `calmest_pick` 확인, 몸 겹침 0·복잡도 ≤ `REDRAW_BUSY`(14)면 그 자리에 두고 다시 그리지 않음. 앞으로 만드는 진짜 동화에도 적용
2. **샘플 다시 배치 스크립트**(`evals/` 아래, `text_avoid_lab.py`를 바탕으로): 8편 80쪽마다 지금 `_arrange`와 같은 자리 찾기 호출 1번(글 덩어리 + 캐릭터 칸 + 의성어 근원), 다시 그리기는 하지 않음. 별표 말이 있는 쪽은 지금 규칙으로 `soundWord`를 놓고, 자리가 없으면 null
3. **미리보기 페이지**: 쪽마다 옛 배치 / 새 배치를 나란히, 글자는 프론트와 같은 2.35% 크기로. "자리 없어 가장 조용한 곳에 둠"인 쪽과 의성어가 빠진 쪽을 표시
4. **사용자가 다시 그릴 쪽 고름**
5. **고른 쪽만 다시 그림**: 원래 그림 지시·캐릭터 시트가 남아 있지 않으므로, **지금 쪽 그림을 참고 그림으로 넣고 "같은 장면·같은 인물, 글 들어갈 쪽을 비워서"** 그림 수정으로 다시 그림(인물 생김새 유지가 목적, Claude 판단). 그 쪽만 다시 배치
6. **결과 폴더**: 지금 양식 그대로(`cover.webp`, `page-01~10.webp`, `story.json`: cardId·cardTitle·title·cover·pageCount·pages[pageNo, text, image, textPosition, textBlocks, soundWord]). `textBlocks`·`soundWord` 모양은 Spring 책 응답(`BookResponse.Page`)과 똑같이(색 DARK/LIGHT 대문자, `soundWord {text, color #RRGGBB, pieces[{text,x,y,side}]}`). 원본은 `샘플동화-1106/`로 남겨 둠
7. 프론트 전달은 사용자가(카톡). 필요하면 프론트 이슈

## 비용·확인

- 2~3단계: 자리 찾기 80번, 약 400원(11/16 20쪽 ≈ 100원 기준)
- 5단계: 다시 그리는 쪽마다 약 40원 + 다시 배치. 쪽 수는 4단계에서 정해짐 → 그때 다시 말하고 묻기
- 확인: 미리보기에서 사용자가 눈으로 확인. 새 `story.json`을 프론트 `StoryReader`로 띄워 글 잘림·의성어 위치 확인(로컬 프론트, 사용자가 원하면)
